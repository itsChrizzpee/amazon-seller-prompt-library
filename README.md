# Amazon-Seller Prompt-Library

70 Prompts für Amazon-Seller, 10 pro Bereich: Margenkalkulator, Produktoptimierung, Verhandlung, Produktsuche, Ads-Optimierung, Geld sparen und KW-Tracking.

Öffne `index.html` im Browser. Jeder Prompt hat einen Kopieren-Button. Ersetze alles in [eckigen Klammern] durch deine Zahlen.

## Regeln

- Keine erfundenen Zahlen: Gebühren und Schwellen sind Platzhalter.
- ACoS immer mit Basis (brutto oder netto) und Zeitfenster angeben.
- Ads-Prompts liefern nur Vorschläge, Änderungen brauchen eine Freigabe.
- Keine Scraping-Prompts: Daten fügst du selbst ein.
- Steuer-, Zoll- und Rechtsfragen sind Checklisten, keine Auskunft.
